# DESIGN.md — 디자인 시스템 (모바일 / NativeWind)

TeamUp 모바일 앱의 디자인 기준. 웹 `DESIGN.md`에서 **랜딩(마케팅) 영역을 제외**하고 앱 내부 톤만 가져와 RN/NativeWind로 재정의한 것. 브랜드 색·타이포 감각은 웹과 통일.

---

## 0. 핵심 원칙

- 모바일은 **앱 내부 톤 하나**로 통일 — 담백하고 기능적. (웹의 화려한 랜딩은 모바일에 없음)
- 웹과 하나의 브랜드로 묶는 공통 요소: **앰버 포인트 컬러 + 따뜻한 먹 텍스트(#2B2620)**.
- 기반: NativeWind(RN용 Tailwind) + React Native Reusables(shadcn RN 포트).

---

## 1. 컬러 팔레트 (브랜드 · 공통)

| 이름 | HEX | 역할 |
|------|-----|------|
| Amber | `#FFA940` | 포인트 · 버튼 · 강조 · 활성 상태 |
| Amber Deep | `#F08C00` | 눌림 · 진한 강조 |
| Amber Soft | `#FFF4E3` | 옅은 배경 블록 · 뱃지 배경 |
| Ink | `#2B2620` | 본문 텍스트 (순검정 대신 따뜻한 먹) |
| Ink Soft | `#6B6257` | 보조 텍스트 |
| Canvas | `#FFFFFF` | 기본 배경 |

이 토큰을 `tailwind.config.js`(NativeWind)와 `src/config`에 정의해 사용. **하드코딩 금지.**

### 앰버 사용 규칙 (중요, 웹과 동일)
- 앰버는 밝은 색이라 흰 배경 위 **텍스트로 쓰면 대비가 약함** → 글자색으로 쓰지 말 것.
- 앰버는 **버튼 배경 · 아이콘 · 게이지 · 활성 탭**으로만.
- 앰버 버튼 위 글자는 `#2B2620`(진한 먹)으로. 흰 글자 금지.

---

## 2. 타이포그래피 (모바일)

- 모바일은 밀도 우선 — 본문 14~16px 중심. (웹 랜딩의 큰 헤드라인 스케일은 안 씀)
- 위계: 화면 제목 20~24 굵게 / 섹션 16~18 / 본문 14~16 / 캡션 12~13.
- 시스템 폰트 기본(원하면 Pretendard 임베드 가능하나 파일럿 필수는 아님).

---

## 3. 앱 내부 컴포넌트 톤 (웹 앱 내부와 통일)

- **버튼(primary)**: 앰버 배경 `#FFA940` / 텍스트 `#2B2620` / radius 8.
- **버튼(secondary)**: 투명 배경 / 먹 테두리 / 먹 텍스트.
- **카드**: 흰 배경 / 옅은 테두리 / radius 12 / 그림자 최소. 구분은 여백·테두리로.
- **뱃지(모집 유형 등)**: 옅은 앰버 배경 + 먹 텍스트, 또는 먹 배경 + 흰 텍스트.
- **완성도 게이지**: 앰버로 채워지는 프로그레스 바.
- **입력 필드**: 흰 배경 / 옅은 테두리 / 포커스 시 앰버 테두리 / 에러 시 빨간 테두리+메시지.
- **활성 탭·선택 필터**: 앰버 배경 + 먹 텍스트, 또는 먹 배경 + 흰 텍스트 중 하나로 통일.

---

## 4. 모바일 특화 메모

- **터치 타겟**: 최소 44×44pt. 목록 카드·버튼 여유 있게.
- **Safe Area**: `react-native-safe-area-context`로 노치/홈 인디케이터 회피.
- **하단 탭**: 모집 / 대시보드. 활성 아이콘·라벨 앰버.
- **스크롤 리스트**: `FlatList` 사용(대량 목록 성능). 당겨서 새로고침(refetch) 지원 권장.
- **로딩**: 스켈레톤(스피너보다 선호). 상세는 스켈레톤 카드.
- **다크모드**: 파일럿 범위 밖(`app.json` userInterfaceStyle: light 고정).
