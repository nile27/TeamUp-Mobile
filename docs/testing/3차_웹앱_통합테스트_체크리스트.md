# 3차 웹+앱 통합 테스트 체크리스트

> 작성일: 2026-08-25. 대상: 오늘 하루 동안 모바일에 추가된 것 전체(둘러보기 UX, 웹 랜딩 링크, 지원 상태/모집 목록 Realtime, 커뮤니티 화면, 좋아요·댓글 UX 수정) + `2차_알파테스트_체크리스트.md`에서 아직 체크 안 된 항목 이어서. **웹과 모바일을 같이 켜놓고 교차 확인하는 항목이 많음** — 웹(`team-up-olive.vercel.app`)과 모바일 앱(Metro 재연결) 둘 다 준비해서 진행.

---

## 1. 오늘 새로 만든 기능 (모바일 단독 확인)

- [ ] **로그인 화면 웹 랜딩 링크**: "TeamUp이 궁금하다면? 서비스 소개 보기" 탭 → 시스템 브라우저로 웹 랜딩 열리는지
- [ ] **둘러보기**: 로그인 없이 모집 목록/상세 진입 가능한지, 지원하기 누르면 로그인 화면으로 유도, 마이페이지 탭 누르면 로그인 유도 문구 뜨는지
- [ ] **계정 전환 캐시**: 로그아웃 후 다른 계정으로 로그인 → 이전 계정의 지원 상태가 안 섞이는지
- [ ] **커뮤니티 목록**: 태그 필터(전체/아이디어/질문/기타) 토글, pull-to-refresh, 빈 상태 문구
- [ ] **커뮤니티 상세**: 글 내용·작성자·댓글 목록 표시
- [ ] **좋아요**: 하트 이모지(❤️/🤍)로 표시되는지, 탭하면 즉시(서버 응답 기다리지 않고) 바뀌는지(낙관적 업데이트), 실패 시 원상복구되는지(오프라인 등에서 확인)
- [ ] **댓글 작성**: 입력 없을 땐 버튼이 회색(비활성), 텍스트 입력하면 주황색(활성)으로 바뀌는지
- [ ] **댓글 여러 번 작성**: 한 계정으로 같은 글에 댓글 2개 이상 작성 → 전부 정상 등록되는지 (원래 제한 없음, 확인만)
- [ ] **키보드 가림**: 댓글 입력창에 포커스 → 키보드가 입력창을 가리지 않는지 (Android/iOS 둘 다 있으면 각각)
- [ ] 비로그인 상태로 좋아요/댓글 시도 → 로그인 화면으로 유도되는지

## 2. Realtime — 웹 + 모바일 동시에 켜놓고 확인 (오늘 핵심 기능)

- [ ] **지원 상태**: 모바일 마이페이지 화면을 열어둔 채로, 웹에서 같은 계정의 지원건을 수락/거절 처리 → 모바일에서 탭 이동 등 아무 조작 없이 바로 상태가 바뀌는지
- [ ] 위 상태에서 모바일 앱을 잠깐 백그라운드로 보냈다가 복귀해도 반영되는지
- [ ] **모집 목록**: 모바일 모집 목록 화면을 열어둔 채로, 웹에서 새 모집 하나 등록 → 모바일에서 새로고침 없이 바로 목록에 뜨는지
- [ ] 웹에서 기존 모집 상태를 변경(마감 등) → 모바일 목록/상세에 반영되는지

## 3. 웹 ↔ 모바일 크로스체크 (그 외)

- [ ] 모바일에서 커뮤니티 글에 좋아요/댓글 → **웹**에서 같은 글 보면 반영돼 있는지
- [ ] 웹에서 커뮤니티 글에 좋아요/댓글 → **모바일**에서 반영되는지 (실시간 아니어도 됨, 새로고침 시 확인)
- [ ] 웹에서 모집 작성자 계정으로 지원자 관리 화면 → 모바일발 지원이 보이는지 (2차 체크리스트 이월 항목)

## 4. `2차_알파테스트_체크리스트.md` 이월 항목 (아직 미확인)
